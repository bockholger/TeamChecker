# Team-Check für iPad (Daten lokal)

Dateien: index.html, manifest.json, sw.js, icon.png (alle vier müssen zusammen hochgeladen werden).

## Einmalig bereitstellen (GitHub Pages, kostenlos)
1. Konto auf github.com, "New repository" (z. B. team-check), Sichtbarkeit Public. Es liegen nur Programmdateien darin, keine Daten.
2. "uploading an existing file": die vier Dateien hochladen, "Commit changes".
3. Settings > Pages > Deploy from a branch > main / (root) > Save.
4. Nach 1-2 Minuten erscheint die Adresse https://BENUTZERNAME.github.io/team-check/

## Auf dem iPad
1. Adresse in Safari öffnen > Teilen > "Zum Home-Bildschirm" > Hinzufügen.
2. Nur noch über das Symbol auf dem Home-Bildschirm benutzen (dort liegen die Daten, getrennt von Safari).
3. TrainerIn-Modus: erste PIN festlegen, Wiederherstellungscode notieren.
4. Regelmäßig: TrainerIn-Modus > Sicherung > "Sicherung speichern" > "In Dateien sichern".

## Grenzen
Daten nur auf diesem iPad. Löschen der Website-Daten / der App löscht alle Einträge (ohne Sicherung unwiederbringlich).
Die PIN schützt nur die Oberfläche, kein echtes Login.
